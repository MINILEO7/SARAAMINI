۱. Git و GitHub
Git چیست و چه کاربردی دارد؟
Git یک سیستم کنترل نسخه (Version Control System) است که برای مدیریت تغییرات فایل‌ها و پروژه‌ها استفاده می‌شود. با Git می‌توان تغییرات ایجادشده در یک پروژه را ثبت کرد و در صورت نیاز به نسخه‌های قبلی برگشت.
Git به‌خصوص در پروژه‌های برنامه‌نویسی کاربرد زیادی دارد و به افراد کمک می‌کند بدون اینکه تغییرات یکدیگر را از بین ببرند، روی یک پروژه کار کنند.
کاربردهای Git:
• ثبت تغییرات پروژه
• بازگشت به نسخه‌های قبلی
• مدیریت نسخه‌های مختلف یک پروژه
• همکاری چند نفر روی یک پروژه
• بررسی اینکه چه تغییراتی و توسط چه کسی انجام شده است
GitHub چیست؟
GitHub یک پلتفرم آنلاین برای ذخیره، مدیریت و به اشتراک‌گذاری پروژه‌ها و Repositoryهای Git است. کاربران می‌توانند پروژه‌های خود را در GitHub قرار دهند و با دیگران روی آن‌ها همکاری کنند.
GitHub علاوه بر نگهداری پروژه‌ها، امکاناتی مانند همکاری تیمی، بررسی تغییرات و مدیریت پروژه را نیز فراهم می‌کند.
تفاوت Git و GitHub
به زبان ساده:
Git یک ابزار است، اما GitHub یک سرویس آنلاین است که برای کار با پروژه‌های Git استفاده می‌شود.
Git می‌تواند روی کامپیوتر شخصی اجرا شود و برای مدیریت نسخه‌های پروژه به اینترنت نیاز ندارد. اما GitHub یک سرویس آنلاین است که معمولاً برای ذخیره و به اشتراک گذاشتن Repository و همکاری با دیگران استفاده می‌شود.

۳. HTTP و HTTPS
HTTP چیست؟
HTTP مخفف HyperText Transfer Protocol است و یک پروتکل برای انتقال اطلاعات بین مرورگر و سرور در اینترنت است.
وقتی وارد یک وب‌سایت می‌شویم، مرورگر برای دریافت اطلاعات از سرور درخواست ارسال می‌کند و سرور نیز پاسخ مناسب را برمی‌گرداند.
HTTPS چیست؟
HTTPS مخفف HyperText Transfer Protocol Secure است.
HTTPS همانند HTTP برای ارتباط بین مرورگر و سرور استفاده می‌شود، اما اطلاعات در این ارتباط رمزنگاری می‌شوند تا امنیت بیشتری داشته باشند.
تفاوت HTTP و HTTPS
مهم‌ترین تفاوت این دو، امنیت ارتباط است.
در HTTP اطلاعات به صورت رمزنگاری‌شده منتقل نمی‌شوند، اما در HTTPS ارتباط بین کاربر و سرور با استفاده از رمزنگاری محافظت می‌شود.
به همین دلیل HTTPS برای انتقال اطلاعات حساس مانند رمز عبور، اطلاعات حساب کاربری و اطلاعات پرداخت مناسب‌تر است.
چرا امروزه بیشتر وب‌سایت‌ها از HTTPS استفاده می‌کنند؟
چون HTTPS امنیت ارتباط بین کاربر و وب‌سایت را افزایش می‌دهد و احتمال دسترسی افراد غیرمجاز به اطلاعات منتقل‌شده را کاهش می‌دهد.
همچنین مرورگرهای امروزی HTTPS را برای بسیاری از قابلیت‌ها و وب‌سایت‌ها به‌عنوان استاندارد امن‌تر ترجیح می‌دهند.
۴. URL
URL چیست؟
URL مخفف Uniform Resource Locator است و به آدرسی گفته می‌شود که برای دسترسی به یک منبع در اینترنت استفاده می‌شود.
مثلاً:
https://www.example.com/products?id=25
یک URL می‌تواند از بخش‌های مختلفی تشکیل شده باشد.
بررسی قسمت‌های یک URL
برای مثال:
https://www.example.com/products?id=25
1. https — Protocol
مشخص می‌کند برای ارتباط با سرور از چه پروتکلی استفاده می‌شود.
2. www — Subdomain
یک زیردامنه است که در بعضی وب‌سایت‌ها استفاده می‌شود.
3. example.com — Domain
نام دامنه وب‌سایت است.
4. /products — Path
مسیر منبع یا صفحه موردنظر در وب‌سایت را مشخص می‌کند.
5. ?id=25 — Query String
اطلاعاتی را به صورت پارامتر به سرور ارسال می‌کند. در اینجا مقدار id برابر 25 است.
۵. GET و POST
GET چیست؟
GET یکی از روش‌های HTTP برای دریافت اطلاعات از سرور است.
در درخواست GET معمولاً اطلاعات موردنظر برای جست‌وجو یا فیلتر در URL قرار می‌گیرند.
مثلاً وقتی در یک فروشگاه اینترنتی محصولات یک دسته‌بندی را جست‌وجو می‌کنیم، می‌توان از GET استفاده کرد.
مثال:
GET /products?category=shoes
در این درخواست از سرور خواسته می‌شود محصولات مربوط به دسته‌بندی کفش را برگرداند.
POST چیست؟
POST یکی دیگر از روش‌های HTTP است که معمولاً برای ارسال اطلاعات به سرور استفاده می‌شود.
مثلاً وقتی در یک سایت فرم ثبت‌نام را پر می‌کنیم، اطلاعات فرم می‌تواند با یک درخواست POST به سرور ارسال شود.
مثال:
POST /students
و اطلاعات دانشجو در بدنه درخواست ارسال می‌شود.
تفاوت GET و POST
GETPOSTمعمولاً برای دریافت اطلاعات استمعمولاً برای ارسال اطلاعات استپارامترها معمولاً در URL قرار می‌گیرنداطلاعات معمولاً در Body درخواست قرار می‌گیرندمی‌تواند در URL قابل مشاهده باشداطلاعات ارسالی معمولاً در URL نمایش داده نمی‌شوندبرای جست‌وجو و دریافت داده مناسب استبرای ارسال فرم و ایجاد/تغییر داده مناسب است
چه زمانی از GET استفاده می‌کنیم؟
معمولاً زمانی که می‌خواهیم اطلاعاتی را از سرور دریافت کنیم.
مثلاً:
• دریافت لیست دانشجویان
• جست‌وجوی محصول
• دریافت اطلاعات یک کاربر
• دریافت اخبار
مثال API:
GET /students/25
یعنی اطلاعات دانشجویی با شناسه 25 را درخواست می‌کنیم.
چه زمانی از POST استفاده می‌کنیم؟
معمولاً زمانی که می‌خواهیم اطلاعاتی را به سرور ارسال کنیم، مخصوصاً زمانی که قرار است اطلاعات جدیدی ایجاد شود.
مثلاً:
• ثبت‌نام کاربر
• ارسال فرم
• ایجاد یک دانشجوی جدید
• ارسال سفارش
مثال API:
POST /students
و اطلاعات دانشجوی جدید در درخواست ارسال می‌شود.
۶. JSON و XML
JSON چیست؟
JSON مخفف JavaScript Object Notation است.
JSON یک قالب متنی برای ذخیره و انتقال اطلاعات است که ساختاری ساده و قابل خواندن برای انسان و ماشین دارد.
JSON در برنامه‌نویسی و به‌خصوص ارتباط بین برنامه‌ها و APIها بسیار پرکاربرد است.
مثال:
{ "name": "Sara", "studentId": 1025, "major": "Multimedia" }
XML چیست؟
XML مخفف Extensible Markup Language است.
XML نیز برای ذخیره و انتقال اطلاعات استفاده می‌شود و اطلاعات را با استفاده از تگ‌ها (Tags) مشخص می‌کند.
مثال:
<student> <name>Sara</name> <studentId>1025</studentId> <major>Multimedia</major> </student>
JSON و XML چه کاربردی دارند؟
هر دو می‌توانند برای انتقال اطلاعات بین سیستم‌های مختلف استفاده شوند.
برای مثال، یک برنامه موبایل می‌تواند از یک سرور اطلاعات دانشجویان را دریافت کند و این اطلاعات می‌تواند در قالب JSON یا XML ارسال شود.
